# User Stories

Reference the Writing User Stories final project guide in the course portal for more information about how to complete each of the sections below.

## Outline User Roles

- **Organizer:** a student who creates and manages study sessions
- **Attendee:** a student who looks for and joins study sessions

## Draft User Stories

1. As an organizer, I want to create a study session with a title, course, date, time, and location, so that other students can find and join it.
2. As an organizer, I want to be redirected to my session's page after creating it, so that I can confirm it was posted correctly.
3. As an organizer, I want to edit the details of a session I posted, so that I can fix mistakes or change the time or topic.
4. As an organizer, I want to delete a session that is no longer happening, so that students don't show up to something that was canceled.
5. As an organizer, I want to see who has RSVP'd to my session and whether they are going or maybe, so that I know how many people to expect.
6. As an attendee, I want to browse a list of all upcoming study sessions, so that I can find one to join.
7. As an attendee, I want to filter sessions by course or location, so that I only see sessions relevant to me.
8. As an attendee, I want to sort sessions by date, so that I can see which ones are happening soonest.
9. As an attendee, I want to open a session's detail page, so that I can see its full description, time, location, and who is attending.
10. As an attendee, I want to RSVP to a session as "going" or "maybe", so that the organizer knows whether to expect me.
